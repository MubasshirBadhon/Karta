# Phase 2 — Local Demo Setup

## Prerequisites

1. **Karta Cloud** running locally (`pnpm dev`)
2. **WordPress** with **WooCommerce** installed
3. **Karta plugin** installed in WordPress

## Step-by-Step Demo

### 1. Start Karta Cloud

```bash
cd karta
pnpm dev
```

The app will be available at `http://localhost:3000`.

### 2. Set Up WordPress + WooCommerce

1. Install WordPress locally (e.g., using Local by Flywheel, XAMPP, or Docker)
2. Install and activate WooCommerce
3. Create a few test products:
   - A simple product (e.g., "Classic T-Shirt" — ৳1,500)
   - A variable product (e.g., "Premium T-Shirt" with color/size variations)

### 3. Install Karta Plugin

1. Copy `wordpress-plugin/karta/` to `wp-content/plugins/karta/`
2. Activate the plugin in WordPress admin
3. Go to **Settings → Karta**

### 4. Configure Connection

1. Enter your Karta API URL: `http://localhost:3000`
2. Enter a Connection ID (generated by Karta Cloud)
3. Enter the Connection Secret (from `WORDPRESS_CONNECT_SECRET` in `.env`)
4. Click **Connect**

### 5. Test Connection

1. Click **Test Connection**
2. You should see "Connection successful!"

### 6. Sync Products

1. Click **Sync Products**
2. Wait for the sync to complete
3. You should see the number of products synced

### 7. Verify in Karta Dashboard

1. Open `http://localhost:3000/dashboard/products`
2. You should see your WooCommerce products listed
3. Click on a product to see details including variants

### 8. Test Stock Updates

1. In WooCommerce, change a product's stock quantity
2. In Karta, click **Sync Products** again
3. Verify the stock changed in the Karta dashboard

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Connection failed | Check API URL, Connection ID, and Secret |
| Sync failed | Ensure WooCommerce is active and products exist |
| Products not showing | Check that products are published in WooCommerce |
| Database error | Run `pnpm db:push` to create tables |

## Expected Result

After completing these steps, the Karta dashboard should show real WooCommerce product data, proving that the integration works end-to-end.
